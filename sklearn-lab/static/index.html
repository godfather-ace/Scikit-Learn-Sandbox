Hyperparameter Tuning

Train the same model many times, changing one setting. Watch for the point where training accuracy keeps rising but test accuracy stalls. That gap is overfitting.

The shaded band between the two lines is the generalisation gap: the wider it gets, the more the model is memorising instead of learning.
